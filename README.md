# CITV Slot

Slot lobisi ve karakter sahneleri. **AstrogameWAR bu repo değil.**

| Ürün | Repo | Canlı |
|---|---|---|
| **CITV Slot** | `cihatsarsilmaz/citvapp` | https://cihatsarsilmaz.github.io/citvapp/ |
| **AstrogameWAR** | `cihatsarsilmaz/astrowar-capacitor` | ayrı Capacitor / web deploy |

## Bu repoda ne var

- 18 slot, 18 karakter
- Kompakt tipografi (32 / 14 / 12.5 / 10)
- Karakter Köşesi + tema sesi (`▶ DİNLE`)
- Spin / ante / hız önizlemesi

## Çalıştır

```bash
npm install
npm run dev
```

Web: `Kryptocasino` dalına push → GitHub Pages (`deploy-pages.yml`).
